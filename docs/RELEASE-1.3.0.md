# Computer Use 1.3.0

用户可以在 agent 未实际操控键鼠时正常操作桌面。深蓝色指示与实际输入同步，鼠标位移有 16 像素容差；每次新输入调用或连续批处理开始前显示完整 1.5 秒预告。

人工接管被表示为暂时中断：用户交还后，agent 必须重新观察现场并接续原任务，保留部分结果和批处理断点，避免盲目重放。明确暂停、退出、取消及待回答的问题仍然有效。

会话、agent、轮次身份检查和跨进程原生独占锁确保同一时间只有一个控制者。`computer_ctrl {action:"release"}` / `cu_release` 可以在聊天仍继续时主动释放桌面；正常结束自动释放，不再弹出结束确认菜单。

灯效改为完整直角的 2 像素边线与最多 8 像素内侧柔光，正文区域透明。普通状态没有悬浮文字牌。美工变更保留原状态和动画时序。

验证：46 组回归通过；需要真实前台键盘输入的测试明确跳过。15 组离屏渲染验证四角连续及透明内区。实际安装包通过原生组件哈希校验、18 个 DSH 工具和 21 个 MCP 工具加载检查，打包冒烟没有启动原生输入进程。

发布按仓库流程先进入 next / GitHub prerelease，npm 发布满 24 小时后才可提升 latest。市场稳定频道在提升后获得默认更新；本机可安装明确版本。更新已加载版本后需重启宿主。
